# Contributing

Contributions to EV Vehicle Tracker are welcome.

1. Open an issue describing the bug or feature, including whether it applies to cars, scooters or both.
2. Fork the repository when public, or request collaborator access while private.
3. Create a focused branch: `feat/<name>` or `fix/<name>`.
4. Keep changes modular and offline-first; do not add mandatory cloud services.
5. Add or update tests and documentation.
6. Run `dart format .`, `flutter analyze`, and `flutter test` before opening a pull request.
7. Explain screenshots, migration impacts, permissions and data privacy implications.

Do not include real registration numbers, VINs, addresses, route histories, invoices, credentials or user backups in issues or tests. Use synthetic fixtures. Maintainers review PRs for accessibility, security, compatibility and maintainability.
