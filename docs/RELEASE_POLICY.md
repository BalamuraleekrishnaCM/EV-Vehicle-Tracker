# Release and Store Publication Policy

This project is free and open source under the MIT license. Open source does not grant contributors permission to publish an official app under the project's name.

- Official Google Play and Apple App Store publishing requires explicit approval by @BalamuraleekrishnaCM.
- No automatic deployment to app stores from pull requests or merges.
- Only maintainer-controlled signing keys and store credentials may be used.
- Release candidates require test results, changelog, privacy disclosures, permission review and version bump.
- First stable public release follows the roadmap's acceptance criteria; development versions are not production ready.
- App-store account fees and policies may apply even when the app is free to download.
