# Implementation status

## Implemented in foundation branch
- Flutter Material 3 application entry point.
- Local SQLite vehicle garage and per-vehicle generic ownership records.
- Battery-energy estimate and conservative reserve calculation.
- Limited deterministic route prompt parser.
- Charging station provider interface with honest offline empty result.
- Unit tests for energy calculation and prompt parsing.
- GitHub CI workflow and contribution/governance templates.

## Not yet implemented
- Live GPS, charging station directory, map display and routing engine.
- Automatic Bluetooth, OBD, or manufacturer telematics.
- Battery health diagnostics, live charge availability, community backend.
- Full finance/EMI schedule, document management, reminders, backups and store-ready releases.
- Native Android/iOS platform scaffolding and verified compilation.

These are tracked as roadmap work, not represented as completed functionality.
